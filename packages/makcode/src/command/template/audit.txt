## Audit Scope

Inspect the actual implementation before making claims. Check all relevant layers:

- frontend pages, components, forms, state, validation, API clients, loading states, empty states, and error flows
- backend routes, controllers, services, authorization, validation, business rules, error handling, logging, and background jobs
- database schema, migrations, indexes, relations, constraints, transactions, seed data, and data consistency
- API contracts, DTOs, request/response types, pagination, filtering, rate limits, idempotency, and backwards compatibility
- security risks including auth bypass, insecure direct object references, injection, XSS, CSRF, secrets exposure, unsafe file access, missing validation, over-permissive CORS, and sensitive logging
- reliability and production behavior including concurrency, retries, partial failure, observability, performance bottlenecks, and rollback safety
